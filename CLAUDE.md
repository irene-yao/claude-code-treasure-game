```
npm run build   # production build to ./build
```

No test runner is configured.

## Architecture

Single-page React app (Vite + TypeScript) where all game logic lives in `src/App.tsx`. The UI renders three treasure boxes; one is randomly assigned a treasure on each game start. Players click boxes to reveal contents (+$100 for treasure, -$50 for skeleton). Game ends when the treasure box is found or all boxes are opened.

Key state in `App.tsx`:
- `boxes: Box[]` — array of `{ id, isOpen, hasTreasure }`
- `score: number` — updated inside the `setBoxes` callback (score and box state update together to avoid stale closure issues)
- `gameEnded: boolean` — triggers the end-game banner and locks further clicks

## Key Dependencies

- `motion/react` — animation library used for chest open/hover effects
- `shadcn/ui` + Radix UI — pre-built accessible components in `src/components/ui/`; treat as a library, not source to edit
- Tailwind CSS v4 — utility classes; design tokens defined in `src/styles/globals.css`
- `@vitejs/plugin-react-swc` — SWC-based fast refresh

## Development Notes

- Path alias `@` resolves to `src/` (configured in `vite.config.ts`)
- `vite.config.ts` includes versioned aliases for every dependency — this was generated by the project scaffolding tool; do not remove them
- Build output goes to `./build` (not the default `./dist`)
- Dev server auto-opens the browser on port 3000
- `src/styles/globals.css` defines all CSS custom properties (colors, radius, font sizes); `src/index.css` is the Tailwind entry point — import order in `main.tsx` matters
